# Online Microbiology Laboratory

Учебная веб-лаборатория по микробиологии. Главная и общая навигация доступны на казахском и русском, учебные занятия — на казахском. Все разделы оформлены в единой зелёной палитре.

## Возможности

- Большой интерактивный 3D-стол на главной: детальный бинокулярный микроскоп, учебные листы, папка, справочник, стеклянная посуда и штатив.
- Семь предметов со ссылками на микроскоп, обе работы, каталог, задания, справку и каталог оборудования.
- Подписи главной страницы, справочник и общая навигация на казахском и русском; исходные учебные занятия остаются на казахском. Язык интерфейса запоминается в браузере.
- Ограниченное вращение и масштабирование мышью, касанием и клавиатурой; резервный доступ ко всем разделам при отсутствии или потере WebGL.
- Каталог лабораторного оборудования с описаниями и поиском на русском и казахском языке. В проекте используется только новый 3D-стол на главной.
- Виртуальный окуляр с переключением объективов, настройкой фокуса, увеличения и перемещением изображения.
- Два занятия: наблюдение за учебной моделью микрофлоры полости рта и изучение морфологии микроорганизмов.
- Навигация между разделами, задания и сохранение учебных заметок в браузере.

## Запуск локально

Требуются Node.js 20.19+ (или 22.12+) и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite. Production-сборка:

```bash
pnpm build
pnpm preview
```

## Синхронизация Windows-папки и сборка

Облачная версия и папка на компьютере используют один исходный проект `AkbotaS/onlinemikro`, ветку `main`. Файлы не нужно копировать поверх локальной версии вручную.

После получения проекта запустите `scripts/Update-Onlinemikro.cmd` двойным щелчком. По умолчанию он обновляет папку:

```text
C:\Users\user0\Documents\Codex\2026-11-15\https-github-com-akbotas-onlinemikro-https\work\onlinemikro
```

Для другой папки передайте её первым аргументом. Та же операция доступна через Node.js:

```powershell
node .\scripts\sync-and-build.mjs "C:\путь к проекту\onlinemikro"
```

Нужны Git, Node.js указанной выше версии и pnpm в PATH. Скрипт проверяет репозиторий, ветку `main` и отсутствие локальных изменений, получает обновления, разрешает только fast-forward, устанавливает зависимости по lockfile и выполняет `pnpm build`. Результат — папка `dist` в вашей локальной копии. Исходный код и сборка не загружаются обратно на GitHub этим скриптом.

Если в Windows-папке есть свои изменения, другая ветка или разошедшаяся история, обновление остановится с объяснением. Скрипт не делает stash, reset, принудительную отправку или перезапись локальной работы. Для объединения незакоммиченной локальной версии сначала нужно отдельно сохранить и согласовать её изменения; доступа к диску Windows из облачной среды нет.

Проверка защит обновлятора:

```bash
pnpm test:sync
```

## Управление рабочим столом

- Нажмите на предмет или его номер, чтобы открыть раздел. На телефоне полные названия также доступны в списке под столом.
- Тяните свободное место для вращения; колесо, щипок двумя пальцами и кнопки «+ / −» меняют масштаб. Кнопка сброса возвращает исходный вид.
- Клавиша Tab выбирает предмет или кнопку; Enter открывает предмет. Когда фокус находится в блоке управления видом, стрелки вращают камеру, «+ / −» меняют масштаб, Home сбрасывает вид.
- Книга открывает справочник; Escape закрывает его и возвращает фокус.
- Новая сцена рисуется по запросу, приостанавливается вне экрана и освобождает ресурсы при выходе. При уменьшении анимации в настройках системы инерция камеры отключена.

## Структура проекта

- `src/App.tsx` — страницы, навигация, каталог и первое лабораторное занятие.
- `src/LessonTwo.tsx` — второе лабораторное занятие.
- `src/EquipmentCatalog.tsx` — каталог оборудования с поиском и описаниями без прежнего 3D-стола.
- `src/BenchScene.tsx`, `src/benchModels.ts`, `src/benchMicroscope.ts` — управление новой сценой и локально построенные модели без внешних ресурсов.
- `src/workspace.css` — адаптивный дизайн рабочей области.
- `src/learning-theme.css` — общая зелёная тема учебных страниц, форм, таблиц и элементов управления.
- `scripts/sync-and-build.mjs` — безопасная синхронизация локальной копии с `main` и production-сборка; `scripts/Update-Onlinemikro.cmd` — запуск для указанной Windows-папки.
- `src/HomeDashboard.tsx`, `src/QuickPage.tsx`, `src/SiteTopbar.tsx` — главная страница, задания и общая панель навигации.
- `src/styles.css` и `src/object-info.css` — стили приложения.

## Примечание

Изображение в виртуальном микроскопе — условная учебная симуляция, а не реальная микрофотография. Материал предназначен для обучения и не подходит для медицинской диагностики. Заметки сохраняются локально в браузере (`localStorage`); серверной базы данных в проекте нет.
